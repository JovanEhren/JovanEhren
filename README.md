### 🧩 what I actually do

I write little utilities that exist because something annoyed me enough to fix it —
a PDF I hated, an image that wouldn't delete cleanly, a scraper for articles I was
too lazy to read manually. If it's small, sharp, and solves *one* problem well,
there's a decent chance I built it.

- 🔭 Currently tinkering with tools across **TypeScript, Python, and Kotlin**
- 🛠️ Into scraping, local-first utilities, and Android side projects
